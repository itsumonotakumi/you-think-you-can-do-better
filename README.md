# インシデント対応シミュレーター「じゃ、あなたがやってみて」

**You Think You Can Do Better?** — An incident-response simulator.

実在のセキュリティ事件を下敷きにした架空の会社で、同じ事件を4つの立場から追体験する、テキストベースのインシデント対応シミュレーターです。

> ニュースで事件を見て「対応が遅い」「なぜすぐ公表しない」と思ったことはありませんか。
> では、あなたが当事者の席に座ってみてください。

▶ **遊ぶ**：https://itsumonotakumi.github.io/you-think-you-can-do-better/

## 特徴

- **10シナリオ × 4ロール**：経営者、役員・グループ会社社長、セキュリティ部門長、セキュリティ担当者。同じ事件でも、立場によって「正しい一手」が違います
- **信頼スコア（加点制）**：会社の信頼を傷つければ減点、維持すれば少し加点、回復させれば加点、信頼と売上を伸ばせれば大きく加点
- **ガイドライン準拠**：採点の根拠は IPA・経済産業省・個人情報保護委員会・JPCERT/CC・NIST SP 800-61・CISSP CBK などの公開資料に紐づけます
- **シナリオ差し替え**：世間で新しい事件が起きたら、エンジンに手を入れずシナリオを追加・差し替えできます
- **日本語・英語対応**：言語データを足せば、ほかの言語にも広げられます

## 目的

ITセキュリティへの理解を促すためのツールです。インシデントレスポンスについて学ぶこと、興味を持つこと、事件のときの批判と企業の対応を理解できるようになることを目的にしています。実在の企業を批判するためのものではありません。

## 提供形態

- ブラウザだけで動く Web アプリ（[GitHub Pages](https://itsumonotakumi.github.io/you-think-you-can-do-better/) で公開）
- プレイの記録はブラウザ内に保存します。ランキングが有効なビルドでは、初回プレイの終了時に結果を自動でランキングへ登録します（あとから削除できます）

## ランキング

ランキングは Cloudflare 版（`VITE_API_BASE` を設定したビルド）だけで動きます。GitHub Pages 版のように API を設定していないビルドでは、ニックネームの入力も送信も表示もしません。

### プレイ前にニックネームを決める

ランキングが有効なビルドでは、シナリオとロールを選んだあと、プレイを始める前にニックネーム（1〜16 文字）を決めます。保存した名前は次回から入力済みで表示され、ランキング画面から変更できます。

> 本名や、個人が特定できる名前（社名・メールアドレス・電話番号など）は入れないでください。ニックネームはランキングで誰でも見られます。

> プレイの結果（シナリオ・ロール・選んだ選択肢・ニックネーム）は、終了時に自動でランキングに登録されます。登録した記録は後で削除できます。

### 自動で登録する内容

初回プレイの結果画面で、同意チェックや「送信する」ボタンなしに自動で登録します。2 回目以降は登録せず、順位だけを返します。

- シナリオ ID・版・ロール・モード
- 選んだ選択肢の記録（判断 ID と選択肢 ID の並び）、報告書の選択、記者会見の回答
- ニックネーム（1〜16 文字。URL・制御文字・不適切な語は受け付けません）
- 端末ごとに作るランダムな ID（個人情報ではありません。初回だけ登録する判定に使います）
- 削除用の鍵（端末で作る 32 バイトの乱数。サーバーには SHA-256 のハッシュだけを保存します）
- ボット対策（Cloudflare Turnstile）のトークン

点数は送りません。サーバーが同じエンジンで選択を再生し、点数とランクを計算します（送られた点数は使いません）。

### 登録した記録を削除する

ランキング画面の「自分の記録を削除する」から、確認のうえでこの端末が登録した記録をすべて削除できます。削除した記録はランキングと選択率の集計から外れます。ランキングと選択率の表示はキャッシュしているため、反映まで最大 5 分ほどかかります。

削除のあと（またはニックネーム欄の近く）で「ランキングに参加しない」を選ぶと、以後の自動登録を止められます。

- **登録するのは初回だけ**です。同じ端末・シナリオ・ロール・モードの 2 回目以降は登録せず、順位だけを返します
- **ニックネームはランキングに公開されます。** 本名・電話番号・SNS の ID など、個人を特定できる情報は入れないでください
- **端末 ID と削除用の鍵は端末側で作る値です。** 初回限定は「同じ端末で 2 回登録しない」ための目安で、端末 ID を作り直せば別人として登録でき、厳密な保証はありません。悪用を減らすため、同じ IP から 1 日に登録できる件数を 20 件までに制限しています
- **削除できるのは、この仕組みで登録した記録だけです。** 端末の保存データを消した場合や、この機能より前に登録した記録は、削除用の鍵が無いため画面から削除できません。その場合はリポジトリの Issue（https://github.com/itsumonotakumi/you-think-you-can-do-better/issues）でニックネームとシナリオ名を知らせてください
- **時間は検証していません。** 選択の並びが本当に可能だったかはサーバーで再生して確かめますが、各判断にかかった時間は送っていないため、制限時間モード（hard）で時間を守ったかどうかは保証できません
- **保存期間**は、ランキングの表示に使う間（目安 1 年）です。シナリオを入れ替えたときやランキングを終えるときに、まとめて削除することがあります
- IP アドレスは保存しません。レート制限（1 分あたり 10 回）と 1 日の登録上限のために、IP を秘密鍵で HMAC した値だけを短期間（48 時間以内）持ちます
- 判断ごとの選択率は、新しい 1000 件の記録から集計し、20 件以上集まったときだけ表示します（少数の回答から個人を推測されないようにするため）
- 読み取り（ランキング・選択率）は 60 秒間キャッシュし、混雑時も同じ集計を繰り返しません
- 無料枠の上限に近づいたら、書き込みを止めます（1 日の登録が 20,000 件を超えたら受け付けません）
- ボット対策（Turnstile）は必須です。検証を通った送信だけをレート制限と登録の対象にします

サーバーを自分で立てる場合に必要な設定は `HANDOFF.md` の「ランキング API の本番設定」にまとめています。
